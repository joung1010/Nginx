## Nginx 기본문법 응용

### Nginx 기본 웹 사이트 수정해보기

**❗ 중요:** 앞서 설명드린 것처럼 최신 Nginx에서는 `default.conf` 파일이 존재하지 않을 수 있습니다. 먼저 실제 설정 구조를 확인해보겠습니다.

### **1. 설정 파일 확인하기**

**현재 사용 중인 설정 파일 위치 확인:**

```bash
*# 설정 파일 위치와 문법 검사*
sudo nginx -t

*# 전체 설정 내용 확인 (실제 적용되는 모든 설정)*
sudo nginx -T
```

**설정 파일 탐색:**

```bash
*# conf.d 디렉토리 내용 확인*
ls -la /etc/nginx/conf.d/

*# nginx.conf 파일 확인*
sudo cat /etc/nginx/nginx.conf
```

### **Case 1: default.conf 파일이 존재하는 경우**

```bash
`$ cd /etc/nginx/conf.d/
$ sudo vi default.conf`

`/etc/nginx/conf.d/default.conf`
```

```bash
server {
    listen       80; 
    server_name  localhost;

    *# 📂 / 으로 시작하는 모든 경로를 처리 (ex. /index.html, /images/logo.png)*
    location / {
        *# 🗂️ 파일 시스템 매핑# /test.html 요청 → /usr/share/nginx/html/test.html 파일 응답*
        root   /usr/share/nginx/html;
        
        *# 🏠 기본 파일 우선순위# / 요청 → /usr/share/nginx/html/index.html로 응답# index.html이 없으면 → /usr/share/nginx/html/index.htm으로 응답*
        index  index.html index.htm;
    }

    *# 🚨 서버 에러 페이지 설정*
    error_page   500 502 503 504  /50x.html;
    
    *# 🎯 에러 페이지 파일 위치 지정*
    location = /50x.html {
        root   /usr/share/nginx/html;
    }
}
```

### **Case 2: default.conf가 없고 nginx.conf에 직접 설정된 경우**

```bash
$ sudo vi /etc/nginx/nginx.conf
```

**nginx.conf에서 server 블록 찾기:**

```bash
http {
    *# ... 다른 설정들 ...*
    
    *# 기본 서버 설정 (수정 대상)*
    server {
        listen 80 default_server;
        listen [::]:80 default_server;
        server_name _;
        root /usr/share/nginx/html;    *# 이 경로 확인!*
        
        location / {
            index index.html index.htm;
        }
        
        error_page 404 /404.html;
        error_page 500 502 503 504 /50x.html;
        location = /50x.html {
        }
    }
}
```

### **2. 웹 루트 디렉토리 확인**

**현재 웹 루트 경로 확인:**

```bash
*# 설정에서 root 경로 찾기*
sudo nginx -T | grep -A 5 -B 5 "root"

*# 실제 파일들 확인*
ls -la /usr/share/nginx/html/
```

**일반적인 웹 루트 위치들:**

```bash
*# 배포판별 기본 경로*
Ubuntu/Debian:     /var/www/html/
CentOS/RHEL:       /usr/share/nginx/html/
Docker:            /usr/share/nginx/html/
소스 컴파일:        /usr/local/nginx/html/
```

### **3. 기본 웹 페이지 수정하기**

**웹 루트 디렉토리로 이동:**

```bash

$ ls -la
```

**예상 파일 구조:**

```bash
/usr/share/nginx/html/
```

**index.html 파일 수정:**

### **5. 설정 변경사항 적용**

**문법 검사 후 리로드:**

```bash
*# 설정 파일 문법 검사*
sudo nginx -t

*# 문법이 올바르면 설정 리로드*
sudo nginx -s reload

*# 또는 systemctl 사용*
sudo systemctl reload nginx
```

### **6. 변경사항 확인**

**브라우저에서 확인:**

```bash
*# 메인 페이지 확인*
curl http://localhost/

*# 또는 브라우저에서 http://localhost/ 접속*
```

**에러 페이지 테스트:**

```bash
*# 에러 페이지 직접 확인*
curl http://localhost/50x.html

*# 서버 에러 발생시켜서 에러 페이지 확인 (임시로)*
sudo systemctl stop nginx
curl http://localhost/  *# 연결 거부 에러 발생*
sudo systemctl start nginx
```

### **🔧 conf.d 자동 적용 메커니즘 정리**

1. **파일 생성**: `conf.d/*.conf` 파일 생성
2. **자동 포함**: nginx.conf의 `include` 지시문이 자동으로 읽어들임
3. **문법 검사**: `nginx -t`로 오류 확인
4. **설정 적용**: `nginx -s reload`로 즉시 반영
5. **즉시 사용**: 브라우저에서 바로 확인 가능

**결론**: 네, **`.conf` 확장자 파일을 conf.d에 넣으면 자동으로 설정이 적용**됩니다! 이것이 현대적인 Nginx 설정 관리의 핵심 메커니즘입니다.
